\subsection{Critical Difference}

Refer to Figure~\ref{fig:cd-full} in the main paper. The CD threshold at
$\alpha = 0.05$ for $k = 5$ algorithms and $N$ tasks is 1.477 (Demsar 2006,
Table 5). Agents whose mean ranks differ by more than 1.477 are
significantly different.

\section{Tool Library (30 tools across 8 domains)}
\label{app:tools}

\begin{itemize}
    \item \textbf{Information Retrieval} (5): search\_web, search\_news, fetch\_url, summarize, translate
    \item \textbf{Computation} (5): calculator, unit\_convert, statistics, round, sort
    \item \textbf{Communication} (4): send\_email, send\_sms, send\_push, send\_slack
    \item \textbf{File I/O} (5): read\_file, write\_file, append\_file, list\_files, delete\_file
    \item \textbf{Scheduling} (4): get\_datetime, calendar\_add, calendar\_list, format\_date
    \item \textbf{Data / Database} (4): sql\_query, csv\_filter, db\_insert, json\_transform
    \item \textbf{Image / Vision} (4): image\_resize, image\_crop, image\_classify, ocr\_extract
    \item \textbf{Audio / Speech} (3): audio\_transcribe, text\_to\_speech, audio\_classify
\end{itemize}

Six equivalence groups span these tools:

\begin{itemize}
    \item G1\_search: \texttt{search\_web} $\equiv$ \texttt{search\_news}
    \item G2\_communicate: \texttt{send\_email} $\equiv$ \texttt{send\_sms}
    \item G3\_data\_query: \texttt{sql\_query} $\equiv$ \texttt{csv\_filter}
    \item G4\_visual\_recognize: \texttt{image\_classify} $\equiv$ \texttt{ocr\_extract}
    \item G5\_notify: \texttt{send\_slack} $\equiv$ \texttt{send\_push}
    \item G6\_calendar\_op: \texttt{calendar\_add} $\equiv$ \texttt{calendar\_list}
\end{itemize}

Full JSON schemas for each tool are in \texttt{tools/*.json} (released with the
code archive).

\section{Task Templates (25 across 6 chain lengths)}
\label{app:templates}

The 25 task templates span chain lengths 2--5 and cross all 8 domains. Full
YAML in \texttt{templates/task\_templates.yaml}. Examples:

\begin{itemize}
    \item \emph{T1}: \texttt{search\_web $\to$ send\_email} --- "Look up the
          weather in Paris and email it to alice@example.com."
    \item \emph{T6}: \texttt{calculator $\to$ send\_sms} --- "Compute
          $42 \times 17$ and SMS the result to +1-555-0100."
    \item \emph{T11}: \texttt{search\_web $\to$ statistics $\to$ write\_file}
          --- "Fetch the last 30 days of AAPL closing prices, compute mean and
          stdev, and save as CSV."
    \item \emph{T18}: \texttt{audio\_transcribe $\to$ summarize $\to$ send\_email}
          --- "Transcribe \texttt{meeting.mp3}, summarize the action items,
          and email them to the team."
\end{itemize}

\section{Hyperparameters and Configuration}

\begin{itemize}
    \item Random seed: 42 (default in all scripts)
    \item \texttt{max\_steps}: 10 per task
    \item \texttt{n\_synthetic\_chains} (ChainAware): 50
    \item Bootstrap iterations: 1000
    \item Friedman / Wilcoxon $\alpha$: 0.05 with Bonferroni correction
    \item DeepSeek temperature: 0 (deterministic)
    \item DeepSeek \texttt{max\_tokens}: 1024 per turn
\end{itemize}
